Dexter Programming Language and Interpreter.

  • Dexter is a dynamic and expressive programming language built from scratch!
  • Dexter is designed to be a versatile, easy-to-learn language with a focus on readability and flexibility.
  • Written in Go and Python. (same implementation, twice!)

Key Features:

  • Dynamic Typing: Dexter is dynamically typed, making it flexible and adaptable for various programming tasks.
  • Readable Syntax: The language prioritizes clean and human-readable code, making it an excellent choice for both beginners and experienced developers.
  • Core Constructs: Dexter supports essential programming constructs such as variables, conditionals, loops, functions, and more.
  • Object-Oriented: Dive into the world of object-oriented programming with Dexter's support for classes and inheritance.
  • Interpreter: The tree-walk interpreter for Dexter allows you to execute code seamlessly, gaining a deeper understanding of interpreter construction.

ASHA - A static blogging site generator with batteries included.

  • Asha is a streamlined static blogging site generator designed to simplify the process of creating static websites. Built with Python, it leverages the power of rangeen, markdown2, and flask (jinja2) to provide a seamless experience for developers.
  • The tool is specifically optimized for Python 3.6 and above, ensuring compatibility with modern Python versions.
  • Written in Python using flask, rangeen, and markdown.
  • Install using: pip install asha

Key Features:

  • A simple command-line tool: Commands like init, build, serve and clean make it easy to set up, compile, and maintain your static site.
  • Customization: Edit .md files for blog content and .json files for theme-related and site-wide changes.
  • Folder Structure: A well-organized folder structure is already set up for users.
  • Default Theme: Comes with a built-in theme to get users started quickly.
  • HTML Minification: Ensures that the generated HTML is optimized for faster loading times.
  • Real World Example: "KHERASHANU.COM" uses Asha and Firebase(Hosting only).
